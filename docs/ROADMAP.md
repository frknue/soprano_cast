# Roadmap

Soprano Cast copies Raycast's Root Search and hotkeys. What is left out, and why, is listed
below, followed by what comes next and later.

## Not copied (family conventions)

- The Settings window: `~/.config/soprano-cast/settings.json`, live reloaded; hotkeys and
  aliases are also set from the Action Panel.
- Cloud Sync.
- The Raycast account.
- AI.
- The extension Store.
- Raycast themes: Soprano themes, all dark.

## Raycast import (next)

- Import hotkeys, aliases, favorites, disabled commands, quicklinks and script directories
  from a Raycast `.rayconfig` export into settings.json.

## Later

- Clipboard history.
- Snippets.
- File search.
- Floating notes.
- Emoji picker.
- Window layouts and custom window commands.
- Move window to a Space.
- Resize / Move Window with typed values.
- Unit and currency conversion.
